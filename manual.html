    Blizanci - a Gemini server

    Blizanci is a Gemini protocol server, designed primarily for robustness and security. This is its manual.

    Author: Martin Keegan, Copyright (C) 2020-2026, Martin Keegan. Licensed under the Apache Licence, Version 2.0.

    Features

    • TLS client certificate support
    • single-user CGI
    • distributed PKI: authorisation by subject or issuer of certificates
    • Titan protocol uploads
    • servlet interface for in-process dynamic page generation

    Chapters

    The chapters are written for the operator first (configuration, routing, authorisation, CGI, Titan) and then for the developer (servlets, request handling, internals). Dynamic content is produced by servlets; the contract a servlet module must meet is described, in three layers (module, servlet process, gateway), in the Servlets chapter, with the container's side of the last two.

    • 2. Configuration: keys, sites, realms, start-up errors
    • 3. Routing: route kinds, mounts, regex routes, old-format routes, shadowing
    • 4. Authorisation: policies and realms
    • 5. Servlets: the servlet contract
    • 6. CGI
    • 7. Titan and static files
    • 8. Request handling: connection, request pipeline, percent-decoding
    • 9. Internals: configuration table, servlets lifecycle, supervision tree
    • 10. Logging
