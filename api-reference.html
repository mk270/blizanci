    API Reference blizanci v#7.2.0

    Modules

    blizanci_auth

    The authorisation policies of a route (public, restricted, private) and the checking of a client certificate against them.

    blizanci_cgi

    A servlet that runs CGI scripts, in a ppool queue, via erlexec.

    blizanci_config

    The configuration of a blizanci instance: built from the application environment (sys.config) by from_app_env/0, or from explicit values by the builder functions (new/2, site/3, add_route/2 and so on).

    blizanci_connection

    The first half of the request path: from TLS data arriving at the connection process (start_link/3, the ranch entry point) to the call of blizanci_request:handle_line/4.

    blizanci_log

    Runtime log-level control for blizanci.

    blizanci_osenv

    This module deals with sanitising a proplist of OS environment variables such that it's appropriate for creating a new UNIX subprocess via the erlexec port.

    blizanci_path
    blizanci_pool

    Shared ppool pool lifecycle helpers for the servlets that queue work onto a worker pool (blizanci_cgi, blizanci_titan).

    blizanci_request

    The second half of the request path: from the parsed request line (handle_line/4) to the servlet.

    blizanci_router
    blizanci_servlet

    The servlet contract: what a module must provide to serve routes.

    blizanci_servlet_container

    The process side of the servlet contract (see blizanci_servlet): runs a servlet's request/4 and, if it defers, a container process for its serve/4.

    blizanci_static

    A servlet serving static files from a route's docroot. Its request/4 answers immediately, never deferring to a servlet process: a request for a regular file yields a {file, MimeType, Path} response, a request for a directory is redirected to that directory's index file, and anything else (including paths that escape the docroot) is a file_not_found. Paths are canonicalised and confined by blizanci_path.

    blizanci_status
    blizanci_test_support
    blizanci_titan

    A servlet accepting Titan uploads into a route's docroot, staged in the route's work_dir.

    blizanci_tmpdir
    blizanci_urlpath

    Percent-decoding of the path of a request URL, and the reverse for redirects. This is the one place where a request path is decoded.

    blizanci_x509

    This module handles most of the certificate-related functionality.
