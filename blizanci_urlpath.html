    blizanci_urlpath (blizanci v7.5.0)

    Percent-decoding of the path of a request URL, and the reverse for redirects. This is the one place where a request path is decoded.

    See the manual chapter Request handling.

    Summary

    Types

    decoded()

    Functions

    decode_path(Path)

    Decode the (already normalised, leading-slash-free) path of a request. A malformed escape is request_not_parsed; a path that decodes to something not allowed is bad_filename. These are the names of the Gemini status codes (see blizanci_status).

    encode_path(Path)

    The reverse of decode_path/1, for a path that is going into a URL (as in a redirect): each segment is percent-encoded, so that spaces, "%", "?", "#" and so on in a name survive, and the segments are joined with "/". Decoding the result gives the path back.

    split_titan(Fragment)

    A Titan path carries its parameters after the first ";" of the raw path ("name;size=3;mime=..."). Split the raw path there, before any decoding, so that an escaped ";" in the name can never be mistaken for the start of the parameters. Returns the file part and the parameters (everything after the ";", still raw), or none if there is no ";".
