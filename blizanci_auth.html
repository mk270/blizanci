    blizanci_auth (blizanci v7.5.0)

    The authorisation policies of a route (public, restricted, private) and the checking of a client certificate against them.

    See the manual chapter Authorisation.

    add_realm(Realms, Name, Files)

    Add a realm to a realm table, reading and decoding its CA files now. A realm may have no files; a private route on it authorises nobody.

    Check if a route's authorisation policy permits a given request

    realm(Name)

    The one way to make a realm: a non-empty, case-sensitive name of printable ASCII, at most 64 characters.

    realm_table(Defs)

    Build a realm table from a list of {Name, Files}, as in the sys.config key realms.

    valid_authz_policy(Policy, Realms)

    Check if the argument represents a valid authorisation policy, resolving any realms against a realm table (see realm_table/1).

    Types

    authorisation()

    -type authorisation() ::
          public | restricted |
          {private,
           [string()] | [realm()],
           [#'OTPCertificate'{tbsCertificate :: term(),
                              signatureAlgorithm :: term(),
                              signature :: term()}]}.

    raw_peer_cert()

    -type raw_peer_cert() :: {ok, public_key:der_encoded()} | {error, term()}.

    realm()

    -type realm() :: {realm, binary()}.

    realm_table()

    -type realm_table() ::
          #{realm() =>
                {[string()],
                 [#'OTPCertificate'{tbsCertificate :: term(),
                                    signatureAlgorithm :: term(),
                                    signature :: term()}]}}.

    request_details()

    -type request_details() ::
          #{client_cert := raw_peer_cert(),
            query := binary(),
            rest_of_input := binary(),
            scheme := binary(),
            host := binary(),
            port := integer(),
            path := binary()}.

    authorised(AuthPolicy, Request)

    -spec authorised(AuthPolicy, Request) -> Result
                    when
                        AuthPolicy :: authorisation(),
                        Request :: request_details(),
                        Result :: authorised | {error_code, atom()}.

    Check if a route's authorisation policy permits a given request

    • AuthPolicy: the authorisation policy associated with the route
    • Request: the Gemini request
