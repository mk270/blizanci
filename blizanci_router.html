    prepare(RouteInfo, Realms, Opts)

    -spec prepare(RouteInfo, Realms, Opts) -> Result
                 when
                     RouteInfo :: [route_info()],
                     Realms :: realm_table(),
                     Opts :: prepare_opts(),
                     Result :: {ok, [route()]} | {error, term()}.

    As prepare/2, with options. Routes are one ordered list, first match wins. An error names the route: {bad_route, Index, Kind, Reason}, where Index is the 1-based position in the list, Kind is mount, regex, tuple (the old format) or unknown, and Reason says what is wrong.

    Old-format routes are translated, not refused. If there are any, one warning is logged saying how many. New-format routes never trigger it.

    A table that validated is also checked for shadowed routes, which can never be reached because an earlier route of the same protocol matches every request they could. One warning is logged for each. This only warns, and can be turned off with the option warn_shadowed (default true). The rules are in the manual chapter 'Routing', section 'Shadowing'.

Warnings are logged only when every route built. The upload directory check of prepare/3 is not made; see check_upload_dirs/1, which the caller runs on the routes.

    route(Proto, Path, Request, Config)

    -spec route(Proto, Path, Request, Config) -> Response
               when
                   Proto :: atom(),
                   Path :: binary(),
                   Request :: request_details(),
                   Config :: server_config(),
                   Response :: gemini_response().

    Route a Gemini request to a handler.

    The Config provides a routing table, which is an ordered list of regular expressions and associated handler modules. route/3 searches for whether the Request matches any of these routes, and if so dispatches it to the appropriate handler module.

    • Proto: the atom gemini or similar
    • Path: the Path in the Gemini request
    • Request: the Gemini request
    • Config: the server configuration, including the routing table
