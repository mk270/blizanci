    start(Queue, Max, Module)

    -spec start(Queue, Max, Module) -> Result
               when
                   Queue :: atom(),
                   Max :: pos_integer(),
                   Module :: module(),
                   Result :: ok | {error, term()}.

    Start the named pool, of at most Max workers of Module. A pool that is already running under the name is left alone and is ok.

    The arguments are checked here, before ppool is called, in the order name, limit, module: Queue must be an atom (other than undefined), Max an integer of at least 1, and Module an atom. A bad one gives {error, {invalid_name, Queue}}, {error, {invalid_limit, Max}} or {error, {invalid_module, Module}} (ppool's own error shapes), and nothing is started or touched. This is deliberate defence in depth: the spec below is not enforced at run time, and the limits may one day come from configuration rather than being constants.

    Any other refusal by ppool (or a name held by some other registered process) is returned as {error, Reason}, Reason being ppool's, unchanged.
