    blizanci_config (blizanci v7.2.0)

    The configuration of a blizanci instance: built from the application environment (sys.config) by from_app_env/0, or from explicit values by the builder functions (new/2, site/3, add_route/2 and so on).

    See the manual chapter Configuration.

    site_wants_client_cert(Routes)

    Whether a site with these routes should ask the client for a certificate during the TLS handshake: true if any route, gemini or titan, is restricted or private, false if every route is public (or there are none). The path is not known at handshake time, so one such route means every client is asked. A site that does not ask never has a certificate sent to it, which matters in TLS 1.2, where the client certificate travels unencrypted.

    authorisation()

    -type authorisation() ::
          public | restricted |
          {private,
           [string()] | [realm()],
           [#'OTPCertificate'{tbsCertificate :: term(),
                              signatureAlgorithm :: term(),
                              signature :: term()}]}.

    authorisation_config()

    -type authorisation_config() ::
          public | restricted | {private, [string()]} | {private, realm() | [realm()]}.

    config()

    -type config() :: #config{global :: global_config(), sites :: [site()]}.

    global_config()

    -type global_config() :: #global{port :: term(), servlets :: term()}.

    mp()

    -type mp() :: {re_pattern, _, _, _, _}.

    pair_error()

    -type pair_error() ::
          {cert_key_mismatch, binary(), term(), term()} |
          {bad_certfile, binary(), term()} |
          {bad_keyfile, binary(), term()}.

    realm()

    -type realm() :: {realm, binary()}.

    realm_table()

    -type realm_table() ::
          #{realm() =>
                {[string()],
                 [#'OTPCertificate'{tbsCertificate :: term(),
                                    signatureAlgorithm :: term(),
                                    signature :: term()}]}}.

    route()

    -type route() ::
          #route{proto :: atom(),
                 selector :: selector(),
                 module :: module(),
                 auth_policy :: authorisation(),
                 options :: map()}.

    selector()

    -type selector() :: {mount, binary()} | {regex, mp()} | {legacy, mp()}.

    site()

    -type site() ::
          #site{hostname :: binary(), certfile :: string(), keyfile :: string(), routing :: [route()]}.
