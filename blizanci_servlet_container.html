    request(Module, Matches, Request, ServerConfig, RouteOpts)

    -spec request(Module, Matches, Request, ServerConfig, RouteOpts) -> Result
                 when
                     Module :: module(),
                     Matches :: path_matches(),
                     Request :: request_details(),
                     ServerConfig :: server_config(),
                     RouteOpts :: map(),
                     Result :: gemini_response().

    Called by the router, in the connection process, to dispatch a request to a specific handler.

    • Module: the module implementing the handler
    • Matches: a map of binary keys to binary values: what each named group of the route's pattern captured (see blizanci_servlet)
    • Request: the request
    • ServerConfig: the configuration for the Gemini server
    • RouteOpts: the configuration to be passed to the servlet module

    The function calls Module:request(Matches, Request, ServerConfig, RouteOpts), which may return either {immediate, Response} or the atom defer. Where it is indicated that the response will be deferred, a new container process is started, and in it Module:serve(Matches, Req, ServerConfig, RouteOpts) is called. This sets things up for the results of the request to be notified back to the caller (of request/5), which is a ranch handler for the Gemini protocol. The result here is then {init_servlet, Pid} (or an internal-server-error code if the process did not start).
